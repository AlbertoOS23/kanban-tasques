# Kanban de tareas

Aplicación web de tipo Kanban desarrollada con HTML, Tailwind, css y JavaScript.

## Funciones

- Crear tareas
- Editar tareas
- Filtrar y buscar
- Persistencia con localStorage

## Tecnologías

- HTML5
- TailWind y CSS
- JavaScript

## Guía de uso

- Para crear una tarea, hay que escribir el título, la descripción, elegir su prioridad y añadir la fecha límite. La ID de la tarea se crea sola.
- Para filtrar las tareas, simplemente elija qué filtros quiere aplicar y se verá aplicada directamente en la tabla.
- Para cambiar el estado de una tarea, se puede elegir entre cambiarlo con la lista desplegable dentro de su tarjeta o arrastrando la tarjeta a la columna deseada.
- Para editar la información de una tarea, sólo hay que darela al botón de editar y cambiar la información que desea editar en el formulario de la izquierda.
- Para eliminar una tarea, hay que pulsar el botón de eliminar de la tarjeta y confirmar que desea hacerlo.
